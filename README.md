# ММ — сайт

Страница мониторинга DeFi 1 / DeFi 2 в дизайне Маяка. Только показывает готовые числа ММ.

- `index.html` — страница (оформление Маяка без изменений).
- `api/data.js` — читает `site-data.json` из приватного репозитория MAYAK-monitoring (ветка `site-data`)
  токеном `MM_GITHUB_READ_TOKEN` (Contents: Read-only, хранится только в Vercel) и отдаёт его странице.
  Расчётов нет: доход, капитал, APR, сводки, доли и доход по дням считает ММ.

Здесь нет данных портфеля и адресов. Сайт закрыт Vercel Deployment Protection.
